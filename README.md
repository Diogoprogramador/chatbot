Chatbot Interativo em Python
Este é um chatbot simples desenvolvido em Python que pode responder a perguntas pré-definidas em várias categorias, como clima, saúde, curiosidades sobre o Brasil, matemática básica, e muito mais. Ele interage com o usuário de forma divertida e interativa.

Funcionalidades
O chatbot é capaz de:

Responder a perguntas sobre o Brasil (ex: "Qual a capital do Brasil?", "Qual é a comida típica do Brasil?")
Informar o clima e hora atuais (embora o clima não seja acessível diretamente)
Oferecer dicas de saúde e responder a perguntas sobre alimentação saudável
Realizar cálculos básicos de matemática
Contar piadas divertidas
E muito mais!
Como Funciona
O chatbot possui um conjunto de respostas predefinidas para perguntas comuns. Quando o usuário interage com o chatbot, ele escolhe uma das perguntas, e o chatbot responde com uma das várias respostas possíveis.

Exemplos de Perguntas
"Qual a capital do Brasil?"
"Quanto é 2 + 2?"
"Qual é a data de hoje?"
"Me conte uma piada!"
"Como posso melhorar minha saúde?"
O chatbot também permite que o usuário defina um nome personalizado para ele.

Este projeto não possui dependências externas além do Python, mas certifique-se de ter o Python 3.x instalado.

No terminal, execute o script Python:

bash
Copiar código

O chatbot pedirá para você escolher um nome e então iniciará a interação.

Personalização
Você pode facilmente adicionar novas respostas ou categorias de perguntas. Para isso, basta adicionar novos itens ao dicionário respostas dentro do arquivo chatbot.py.

Exemplo:

python
